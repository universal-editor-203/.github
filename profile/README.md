## What is this?

**Universal Editor** is an independent, open-source, browser-based editor for:

| Module | Description |
|--------|-------------|
| 🎬 **Video** | Filmora-style timeline, FFmpeg.wasm trim / GIF / export |
| 🎮 **ROM** | Organize & inspect game ROMs in-browser |
| 📄 **File** | Text / code edit + download |
| 🎵 **Music** | Load & preview audio |
| 🦀 **Rust** | Write, template, download `.rs` |

Live site → **[universal-editor-203.github.io](https://universal-editor-203.github.io/)**
